| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | app.js render path (query → DOM) | mitigate | Zero `innerHTML` in app.js — all DOM built via `createElement` + `textContent` (RESEARCH Pattern 2/Pitfall 4). | T-04-02 | Tampering | app.js regex construction (query → RegExp) | mitigate | `esc()` escapes regex metacharacters before query chars enter character classes; `arRegex()` folds the query first then maps each base char to a fixed variant class (no user-supplied regex syntax reaches `new RegExp`). | T-04-03 | Denial of Service | app.js highlight/fuzzy regexes (pathological query) | mitigate | Regexes are anchored to ≤ ~20-char user terms with single-pass `exec()` loops that always advance `lastIndex`; no nested quantifiers over user text (wildcards are fixed literal ranges).
