Follow repo conventions: shebang `#!/usr/bin/env python3`, module docstring explaining the two modes, `UPPER_SNAKE_CASE` module constants, `snake_case` functions with one-line docstrings, single-quoted strings, `print(f"...")` progress messages (no logging framework), parameterized inserts ONLY (`?` placeholders + `executemany` — never f-string values into SQL).

Module constants (exact values):
- `API_URL = 'https://api.alquran.cloud/v1/quran/ms.basmeih'` (whole-Quran single request, D-03)
- `STAGED_FILE = 'data/ms.basmeih.json'`
- `DB_FILE = 'quran.db'`
- `EXPECTED_AYAHS = 6236`
- `EDITION_IDENTIFIER = 'ms.basmeih'`
- `EDITION_META = ('ms.basmeih', 'ms', 'Basmeih', 'Abdullah Muhammad Basmeih', 'text', 'translation')` — API-verbatim per D-09 (identifier, language, name, english_name, format, type)
- `FETCH_TIMEOUT = 60`, `FETCH_RETRIES = 3`, `FETCH_RETRY_DELAY = 2`

Functions:
1. `fetch_basmeih()` — urllib.request.urlopen(API_URL, timeout=FETCH_TIMEOUT), retry up to FETCH_RETRIES times with FETCH_RETRY_DELAYs sleep on `URLError`/`HTTPError`/`TimeoutError`; parse JSON; verify `payload['code'] == 200` and `payload['status'] == 'OK'`, else raise RuntimeError with the code/status; return the parsed dict.
2. `extract_records(payload)` — flatten `payload['data']['surahs']` (114 surahs) → list of `{'number': ayah['number'], 'text': ayah['text']}` for every ayah in every surah (global `number` field). Return sorted by `number`.
3. `validate_records(records)` — assert/raise ValueError if: `len(records) != 6236`; numbers are not exactly `list(range(1, 6237))`; any `text` is missing, `None`, or `.strip() == ''`. Message must name the failing condition.
4. `load_staged()` — open STAGED_FILE with `encoding='utf-8'`, `json.load`, then run `validate_records`. Raise FileNotFoundError with clear message if the file is missing.
5. `cmd_fetch(args)` — `os.makedirs(os.path.dirname(STAGED_FILE) or '.', exist_ok=True)`; fetch → extract → validate → `json.dump(records, f, ensure_ascii=False, indent=2)`; print `f"Wrote {len(records)} ayahs to {STAGED_FILE}"`; return 0. On any exception print `f"Fetch failed: {e}"` and return 1.
6. `cmd_insert(args)` — see below.
7. `main()` — argparse with mutually exclusive `--fetch` / `--insert` and flag `--force` (only meaningful with `--insert`); no subcommand → print usage to stderr, return 2; dispatch to cmd_fetch/cmd_insert; `sys.exit(...)` with the returned code.
8. `if __name__ == '__main__': sys.exit(main())` guard (module importable).

`cmd_insert` behavior (D-06, D-10; executed in plan 01-02, must be fully implemented now):
- If `not os.path.exists(DB_FILE)`: print `"quran.db not found. Run convert_to_sqlite.py first."` and return 1 (D-06).
- `records = load_staged()` (validates 6,236/contiguous/non-empty — D-04). On exception: print message, return 1.
- `db = sqlite3.connect(DB_FILE)`; `db.execute("PRAGMA foreign_keys = ON")`.
- `existing = db.execute("SELECT id FROM editions WHERE identifier = ?", (EDITION_IDENTIFIER,)).fetchone()`.
- If `existing and not args.force`: print `"ms.basmeih already exists in editions — skipping (use --force to re-run)"` (D-10 skip guard), `db.close()`, return 0.
- If `existing and args.force`: `DELETE FROM ayah_edition WHERE edition_id = ?`, then `DELETE FROM editions WHERE id = ?` (FK order: children first).
- Insert edition: `INSERT INTO editions (identifier, language, name, english_name, format, type, created_at, updated_at) VALUES (?,?,?,?,?,?,?,?)` with `EDITION_META + (now, now)`; `now = time.strftime('%Y-%m-%d %H:%M:%S')` (matches existing DB timestamp format). `edition_id = db.execute("SELECT last_insert_rowid()").fetchone()[0]`.
- Build ayah map: `SELECT id, number FROM ayahs` → dict `{number: id}`; verify `len(ayah_map) == 6236` and every staged number is present, else print `"staged numbers do not match ayahs.number"` and return 1.
- Build rows: `[(ayah_map[r['number']], edition_id, r['text'], 0, now, now) for r in records]`.
- `db.executemany("INSERT INTO ayah_edition (ayah_id, edition_id, data, is_audio, created_at, updated_at) VALUES (?,?,?,?,?,?)", rows)`.
- Verification report mirroring convert() (:408-419): `SELECT COUNT(*)` for the inserted edition (must print `6236`), `PRAGMA foreign_key_check` (must print 0 rows), `PRAGMA wal_checkpoint(TRUNCATE)`, `os.path.getsize(DB_FILE)` in MB with one decimal.
- `db.commit()` before the report queries; `db.close()` at end. Wrap insert/query errors in try/except printing `f"Insert failed: {e}"` and returning 1 (rollback via `db.rollback()` if a transaction is open).

Do NOT modify `convert_to_sqlite.py`, `data/quran.sql.zip`, or `README.md` (D-05, D-12, D-13). Do NOT introduce any third-party dependency (D-08).
